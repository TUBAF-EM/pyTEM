# Introduction

The code is merely a class for administrating data that can be
inverted by a combination of the modelling package `empymod`
(Werthmüller et al. 2017) and the inversion framework `pyGIMLi`
(Rücker et al. 2017) using modelling wrappers that support the
use of dual-mode loop-based TEM as well as laterally constrained
inversion.

## References

* Werthmüller, D. (2017): An open-source full 3D electromagnetic
modeler for 1D VTI media in Python: empymod, *Geophysics* 82(6),
WB9-19, [doi:10.1190/GEO2016-0626.1](https://doi.org/10.1190/GEO2016-0626.1)
* Rücker, C., Günther, T., Wagner, F.M. (2017): pyGIMLi: An open-source library for modelling and inversion in geophysics, Computers & Geosciences 109, 106-123, [doi:10.1016/j.cageo.2017.07.011](http://doi.org/10.1016/j.cageo.2017.07.011).
